# 图织天网新版训练性能统计

## 统计结论

本报告仅统计新版 HF 初始化运行 hf_init_full_20260927_081557。日志中第 1 至 100 步连续且无重复，batch size 均为 8，耗时、loss 和梯度范数均为有限数值。

全程 100 步：平均 29.1377 秒/步，中位数 28.9143 秒/步；最短 21.5042 秒，最长 36.1878 秒。按总样本数除以日志步耗时之和，吞吐为 0.2746 样本/秒。

第 50 至 100 步（含两端，共 51 步）：平均 29.6119 秒/步，中位数 29.2153 秒/步，吞吐 0.2702 样本/秒。该窗口用于补充观察，不宣称已证明稳态。

累计批次样本数 800，日志步耗时合计 2913.7743 秒。首步 loss 1.922337，末步 1.414928；不同步使用不同批次，不据此推断验证集精度提升。

## 测试配置与口径

成功配置记录：单卡训练，micro batch 1，梯度累积 8，BF16 参数与 FP32 归约，序列截断长度 1024，最大图片像素 262144，重计算开启。HF 直接初始化，关闭 meta 初始化，load 为空字符串。

数据配置最多选择 1000 条标注，日志累计消费 800 个批次样本；不等于完成全数据集一轮。样本/秒不是 token/秒，也不是在线问答请求吞吐。

平均步耗时直接取日志 elapsed time per iteration 字段的算术平均；吞吐为窗口样本总数除以窗口日志耗时总和。不包含日志字段之外的环境启动、模型加载和最终保存开销，不能当作端到端总耗时。

## 资源记录与限制

仅有第 2 步后的内存记录：allocated 6512.69 MB，max allocated 11410.21 MB，reserved 与 max reserved 均为 11658.00 MB（单位沿用日志）。这些值不是整个 100 步训练的峰值显存。

只有一次运行，未计算跨次波动、置信区间或加速比；未采集完整 NPU 利用率和功耗。未与旧版训练或旧参考日志做精度对齐，旧 2% 结论与旧性能数字不沿用。此文件是可核查的性能统计说明，尚未按官方性能模板逐字段验收。
